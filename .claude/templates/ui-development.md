## 🛠️ 第二阶段：实现

### 步骤 1：先实现结构

**创建 HTML/TSX 结构：**

```tsx
// 示例：项目卡片
export function ProjectCard({ project }: ProjectCardProps) {
  return (
    <div className="project-card">
      <div className="card-header">
        <h3>{project.name}</h3>
        <span className="status">{project.status}</span>
      </div>
      <div className="card-body">
        <p>{project.description}</p>
      </div>
      <div className="card-footer">
        <button>编辑</button>
        <button>删除</button>
      </div>
    </div>
  );
}
```

### 步骤 2：添加样式

**应用设计系统参数：**

```tsx
export function ProjectCard({ project }: ProjectCardProps) {
  return (
    <div className="
      project-card
      glass-effect           /* 玻璃拟态 */
      gold-hover-border      /* 金色悬停边框 */
      p-6                    /* 间距：16px 24px */
      rounded-lg             /* 圆角：8px */
    ">
      {/* ... */}
    </div>
  );
}
```

**样式检查点：**
- [ ] 使用正确的颜色值（从设计系统）
- [ ] 使用正确的间距（8px 网格：4/8/12/16/20/24/32/40/48）
- [ ] 使用正确的圆角（4/8/12px）
- [ ] 玻璃拟态效果（如适用）

### 步骤 3：添加交互

**实现交互逻辑：**

```tsx
export function ProjectCard({ project, onEdit, onDelete }: ProjectCardProps) {
  const [isHovered, setIsHovered] = useState(false);

  return (
    <div
      className="glass-effect gold-hover-border p-6 rounded-lg"
      onMouseEnter={() => setIsHovered(true)}
      onMouseLeave={() => setIsHovered(false)}
    >
      {/* 悬停时显示操作按钮 */}
      {isHovered && (
        <div className="actions">
          <button onClick={() => onEdit(project.id)}>编辑</button>
        </div>
      )}
    </div>
  );
}
```

**交互检查点：**
- [ ] 过渡动画（0.3s ease）
- [ ] 悬停状态
- [ ] 加载状态
- [ ] 错误状态

## ✅ 第三阶段：验证

### 视觉检查清单

**颜色验证：**
- [ ] 背景色是否使用 `#F5F1E8`
- [ ] 导航栏是否使用 `#1A1A1A`（如适用）
- [ ] 品牌色是否使用 `#C9A962`
- [ ] 文字色是否使用 `#1A1A1A` 或 `#5C5548`

**间距验证：**
- [ ] 所有间距是否为 4/8/12/16/20/24/32/40/48px
- [ ] 没有 5/10/15 等非 8px 网格间距

**圆角验证：**
- [ ] 小元素使用 4px
- [ ] 默认使用 8px
- [ ] 大卡片使用 12px

**效果验证：**
- [ ] 卡片是否有玻璃拟态效果
- [ ] 金色元素是否有悬停动画
- [ ] 是否有浮动光晕（如适用）

**布局验证：**
- [ ] 模态框宽度是否为 700px（如适用）
- [ ] 导航栏宽度是否正确（如适用）
- [ ] 响应式断点是否正确

### 代码质量检查清单

- [ ] TypeScript 类型正确

- [ ] 组件可复用

## 📊 第四阶段：原型对比

### 如果存在原型图

**执行以下步骤：**

1. **运行开发服务器**
   ```bash
   npm run dev
   ```

2. **截图当前实现**
   - 浏览器打开 http://localhost:3000
   - 截图你的实现

3. **并排对比**
   - 左侧：原型图
   - 右侧：你的实现
   - 逐项对比

4. **列出差异**
   ```markdown
   ## 对比报告

   ### 一致的部分
   - ✅ 颜色一致
   - ✅ 布局结构一致

   ### 有差异的部分
   - ⚠️ 间距：原型是 24px，实现是 20px
   - ⚠️ 圆角：原型是 12px，实现是 8px
   - ⚠️ 缺少浮动光晕效果

   ### 修复计划
   1. 调整间距为 24px
   2. 调整圆角为 12px
   3. 添加 floating-glow 动画
   ```

5. **修复差异**
   - 逐项修复
   - 重新验证
   - 再次对比

## 💡 最佳实践

### 开发顺序

```
1. 先看设计系统 → 确认参数
2. 再看原型图 → 理解布局
3. 先结构 → 后样式 → 再交互
4. 边实现 → 边验证 → 及时调整
```

### 验证频率

```
每完成一个组件 → 立即验证
每完成一个页面 → 对比原型
每次修改 → 重新验证
```
