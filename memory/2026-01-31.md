# 2026-01-31

## 项目分析

深入分析了 Scripter 项目，发现这是一个多 Agent AI 剧本创作平台。

## 架构设计

设计了完整的多 Agent 框架：
- **Agent 角色矩阵**：剧本医生、角色教练、导演、编剧、读者、制片人、场景设计师
- **通信机制**：Gateway 作为通信中心，支持点对点、广播、订阅/发布
- **任务调度**：基于专长分配任务，支持并行和串行执行
- **协作模式**：串行、并行、协作（多轮对话）
- **冲突解决**：投票、协商、用户仲裁
- **反馈循环**：显式/隐式反馈收集，分析趋势
- **自我演化**：参数调整、技能增强、关系调整

## 核心理念

- **AI 是开发伙伴**，不是替代品
- **多 Agent 协同 > 竞争**
- **演化 > 固化**
- **质量保证**：代码审查、测试、文档三重保障

## 技术栈

- Tailwind CSS 4
- TipTap 编辑器
- Drizzle ORM + PostgreSQL
- 智谱 GLM-4.7（AI）
