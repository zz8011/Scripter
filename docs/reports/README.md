## 🔄 报告流程

### 自动生成

**会话总结** 由 SessionEnd hook 自动生成:
- 文件名: `YYYY-MM-DD-session-{auto-id}.md`
- 内容: 会话摘要、完成任务、决策记录
- 位置: `docs/reports/sessions/`

### 手动创建

**任务/分析/审查报告** 按需创建:
1. 使用报告模板 (见下方)
2. 遵循命名规则
3. 保存到对应子目录
4. 更新本索引文件

---
