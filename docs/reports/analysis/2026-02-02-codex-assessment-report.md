## 1. 项目概述

### 1.1 项目类型和主要功能

**剧灵 (Scripter)** 是一个面向剧本创作者的 AI 辅助写作平台。

**核心理念**: "剧灵，一支懂你的笔" —— 让每个有故事的人都能成为编剧

**主要功能模块**:
- 📝 **剧本编辑器** - 基于 TipTap 的专业剧本格式编辑器
- 🤖 **AI 创作伙伴 (剧灵)** - 智能 AI 助手，提供创作建议
- 📊 **项目管理** - 剧本项目、场景、人物的集中管理
- 🎭 **人物/场景管理** - 角色档案、场景看板
- 🌍 **世界观设定** - 故事背景结构化编辑
- 🎬 **分镜系统** - 视觉化分镜创作
- 📤 **多格式导出** - PDF/Word/纯文本/Fountain 格式导出

### 1.2 技术栈总结

| 层级 | 技术选型 | 版本/说明 |
|------|---------|----------|
| **前端框架** | Next.js | 15.1.4 (App Router) |
| **语言** | TypeScript | 5.x |
| **UI 组件** | shadcn/ui + Tailwind CSS | Tailwind v4 |
| **编辑器** | TipTap | 2.12.2 |
| **状态管理** | Zustand | 5.0.10 |
| **数据库 ORM** | Drizzle ORM | 0.29.0 |
| **数据库** | PostgreSQL | 15+ |
| **认证** | Casdoor | OAuth 2.0 / OIDC |
| **AI 服务** | 智谱 GLM-4.7 | 国产大模型 |
| **PDF 生成** | Puppeteer + Chromium | @sparticuz/chromium |
| **Word 导出** | docx.js | 9.5.1 |
| **拖拽排序** | @dnd-kit | 6.3.1 |
| **测试** | Vitest + Testing Library | 4.0.18 |

## 4. 技术债务和潜在问题

### 🔴 高风险

| 问题 | 影响 | 建议 |
|------|------|------|
| **AI 对话表未定义 Schema** | 对话功能无法正常工作 | 补充完整的数据库 Schema |
| **Agent 系统未完成** | 核心卖点功能缺失 | 优先完成 AgentBus 和技能系统 |
| **Puppeteer 依赖较重** | 服务器资源消耗大 | 考虑使用 Playwright 或云端渲染 |

### 🟡 中风险

| 问题 | 影响 | 建议 |
|------|------|------|
| **类型定义重复** | 维护困难 | 统一类型定义到 `lib/types.ts` |
| **缺少 E2E 测试** | 回归风险 | 添加 Playwright 测试 |
| **环境变量缺少默认值** | 开发体验差 | 完善 `.env.example` |
| **组件 Props 类型不完整** | 类型安全降低 | 补充 Props 类型定义 |

### 🟢 低风险

| 问题 | 影响 | 建议 |
|------|------|------|
| **代码风格不一致** | 可读性 | 配置 ESLint + Prettier |
| **注释过多** | 代码臃肿 | 移除冗余注释 |
| **console.log 未清理** | 生产环境噪音 | 使用 logger.ts 替代 |
