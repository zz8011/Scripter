## 📝 修复记录

### 侧边栏折叠功能优化 (2026-01-25)

**用户反馈**:
> "左边栏折叠按钮放在左边栏右边，右边栏折叠按钮放在右边栏左侧。另外折叠了之后，中间栏要自适应"

**问题分析**:
1. 折叠按钮位置不符合要求
2. 展开按钮被 `overflow-hidden` 裁剪
3. 响应式类 `lg:w-72` 覆盖了 `w-0`

**解决方案**:
1. **移动折叠按钮位置**:
   - 左侧: `right-0 translate-x-1/2` (在侧边栏右边缘，半重叠)
   - 右侧: `left-0 -translate-x-1/2` (在侧边栏左边缘，半重叠)

2. **展开按钮移出 aside 元素**:
   ```tsx
   return (
     <>
       <aside>...</aside>
       {collapsed && <button className="fixed ...">}
     </>
   );
   ```

3. **强制应用折叠宽度**:
   ```tsx
   collapsed && "!w-0 lg:!w-0 min-w-0 opacity-0 pointer-events-none"
   ```

**测试结果**:
```
✓ 左侧边栏折叠按钮在右边栏右边缘
✓ 右侧边栏折叠按钮在右边栏左边缘
✓ 折叠侧边栏后中间区域自适应
  - 折叠前: 672px
  - 折叠左侧后: 960px (+288px)
  - 折叠双侧后: 1279px (+319px)
✓ 折叠后展开按钮出现在屏幕边缘
✓ 展开和折叠功能正常工作
```
