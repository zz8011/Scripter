## 技术决策

| 决策 | 方案 | 理由 |
|------|------|------|
| **主题管理** | 自定义 Context API | 避免引入 next-themes 依赖，减少包大小 |
| **CSS 方式** | CSS 变量 (:root & .dark) | 性能最优，无需额外 CSS-in-JS 库 |
| **图标库** | lucide-react | 项目已使用，保持一致性 |
| **持久化** | localStorage | 简单可靠，符合浏览器标准 |
| **动画** | CSS transition | 平滑且性能好（GPU 加速） |
| **防止闪烁** | suppressHydrationWarning | 避免 React hydration 不匹配警告 |

## 实施细节

### CSS 变量设计

**浅色主题**:
```css
:root {
  --paper-bg: #F5F1E8;    /* 米色背景 */
  --ink-black: #1A1A1A;    /* 深黑色文字 */
  --brand-gold: #C9A962;   /* 品牌金色 */
}
```

**深色主题**:
```css
.dark {
  --paper-bg: #0D0D0D;     /* 深黑色背景 */
  --ink-black: #E8E4DC;     /* 米白色文字 */
  --brand-gold: #C9A962;    /* 品牌金色（保持） */
}
```

**设计原则**:
- 保持品牌金色不变（识别度）
- 反转主色调（背景 ↔ 文字）
- 降低边框对比度（深色模式更柔和）
- 移除深色模式的纸质纹理（保持纯色）

### 组件架构

```
layout.tsx (Root)
  └─ ThemeProvider (Context)
      └─ page.tsx
          └─ ThemeToggle (Consumer)
              ├─ Sun Icon (浅色主题显示)
              └─ Moon Icon (深色主题显示)
```

**数据流**:
```
用户点击 → setTheme('dark') → localStorage → Context 更新 → CSS class 变化
```
