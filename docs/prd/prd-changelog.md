### v2.4 - 剧灵生辰八字系统版
**日期**: 2026-01-23

**变更类型**: 功能新增

**变更说明**:
- 新增剧灵（Juling）生辰八字系统
- 用户注册时间生成八字，决定 AI 说话风格
- 新增诗号生成功能
- 新增不打扰原则和相关性判断
- 新增行为记录系统

**主要变更**:
| 功能 | 说明 |
|------|------|
| 八字性格 | 根据用户注册时间计算生辰八字 |
| 五行风格 | 八字对应五行，决定 AI 说话风格 |
| 诗号生成 | AI 生成人物诗号 |
| 不打扰 | 创作时静默观察，不打扰用户 |
| 相关性判断 | 智能判断何时注入上下文 |

### v2.1 - 技术栈更新版
**日期**: 2026-01-23

**变更类型**: 技术调整

**变更说明**:
- 数据库 ORM 从 Prisma 切换到 Drizzle ORM
- 认证系统从 NextAuth.js 切换到 Casdoor
- AI 文本模型切换到智谱 GLM-4.7
- 新增 AI 图片生成 T8Star 集成

**主要变更**:
| 技术 | v2.0 | v2.1 |
|------|------|------|
| ORM | Prisma | Drizzle ORM |
| 认证 | NextAuth.js | Casdoor |
| AI 文本 | Vercel AI SDK | 智谱 GLM-4.7 |
| AI 图片 | - | T8Star |

**理由**:
- Drizzle: 性能更好，Edge Runtime 支持
- Casdoor: 可视化管理，SSO 内置
- 智谱: 成本降低 95%，中文优化

**文件**: `prd-v2.1-legacy.md`

## 版本命名规则

### 格式
```
v{major}.{minor}
```

### 规则
- **Major**: 重大变更、架构调整（如 v1 → v2）
- **Minor**: 新功能、重要更新（如 v2.0 → v2.1）

### 示例
| 版本 | 类型 | 说明 |
|------|------|------|
| v1.0 → v2.0 | Major | 重大架构调整 |
| v2.0 → v2.1 | Minor | 技术栈更新 |
| v2.1 → v2.2 | Minor | 产品愿景升级 |
| v2.4 → v2.5 | Minor | 功能整合 |

## 文件命名规则

### 当前命名规范（v2.5 起）

| 格式 | 说明 | 示例 |
|------|------|------|
| `prd-v{version}.md` | 当前生效版本 | `prd-v2.5.md` |
| `prd-v{version}-legacy.md` | 历史版本 | `prd-v2.4-legacy.md` |
| `prd-changelog.md` | 变更日志 | 本文档 |

### 废弃命名规范

以下命名规范已废弃，仅供历史参考：

| 废弃格式 | 问题 |
|---------|------|
| `YYYY-MM-DD-scripter-prd-v{version}.md` | 日期冗余 |
| `scripter-prd-v{version}.md` | 项目名冗余 |
| `prd-{version}-final.md` | 非版本化 |

详见 [文件命名规范](../file-naming-convention.md)

## 维护说明

### 更新流程
1. 创建新版本 PRD（如 `prd-v2.6.md`）
2. 将当前版本标记为 legacy（如 `prd-v2.5-legacy.md`）
3. 更新本文档的变更记录
4. 更新 README.md 中的引用

### 版本发布
- **Minor 版本**: 功能更新、重要优化
- **Major 版本**: 重大架构调整、方向变更
