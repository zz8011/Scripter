```
Scripter
├── 创作空间 (Creative Space)
│   ├── 剧本编辑器 (Script Editor)
│   │   ├── TipTap 富文本编辑
│   │   ├── 实时格式检查
│   │   ├── 段落拖拽排序
│   │   └── 版本管理
│   └── 阅读模式 (Reader Mode)
│       ├── 沉浸式阅读视图
│       └── AI 分析注释
│
├── AI 辅助系统 (AI Assistant)
│   ├── 剧灵系统 (Juling)
│   │   ├── 生辰八字性格
│   │   ├── 五行说话风格
│   │   ├── 诗号生成
│   │   └── 自定义名称
│   ├── 交互系统
│   │   ├── 不打扰原则 - 创作时静默
│   │   ├── 相关性判断 - 智能上下文
│   │   └── 行为记录 - 全模块追踪
│   ├── 原子化技能 (Skills)
│   │   ├── 格式修复 (format-fix)
│   │   ├── 对白润色 (dialogue-polish)
│   │   ├── 场景扩展 (scene-expand)
│   │   ├── 节奏分析 (rhythm-analyze)
│   │   ├── 一致性检查 (consistency-check)
│   │   └── 集长计算 (duration-calc)
│   └── 对话模式
│       ├── 对话式 - 自由交流
│       ├── 共创式 - 轮流创作
│       └── 反馈式 - 建议优化
│
├── 项目管理 (Project Management)
│   ├── 控制台 (Dashboard)
│   │   ├── 项目概览
│   │   ├── 今日字数统计
│   │   └── 最近编辑项目
│   ├── 项目创建向导
│   └── 创作进度追踪
│
├── 创作资源 (Creative Resources)
│   ├── 人物管理 (Characters)
│   │   ├── 人物档案卡片
│   │   ├── AI 生成人设
│   │   ├── 诗号生成
│   │   └── 关系图谱
│   ├── 场景管理 (Scenes)
│   │   ├── 看板视图
│   │   ├── 拖拽排序

│   │   └── 自动编号
│   ├── 世界观 (Worldview)
│   │   ├── 多维设定编辑
│   │   └── 结构化展示
│   └── 分镜 (Storyboard)
│       ├── 四栏排版
```

### 2.2 MVP 功能范围

#### P0 必须功能（同步开发）

| 模块 | 功能 | 验收标准 | 优先级 |
|------|------|---------|--------|
| **Dashboard** | 项目概览、今日字数、最近编辑 | 30秒内加载；显示最近5个项目 | P0 |
| **Editor** | A4布局、段落拖拽、格式检查 | 支持4种元素；格式检查准确率≥95% | P0 |
| **Characters** | 人物卡片、AI生成人设、诗号 | 卡片流展示；AI生成诗号 | P0 |
| **Scenes** | 看板管理、环境标签、拖拽排序 | 拖动调整顺序；自动重新编号 | P0 |
| **Worldview** | 多维设定、结构化编辑 | 时代/地理/阶层分类编辑 | P0 |
| **Storyboard** | 四栏排版、运镜建议 | 专业格式显示 | P0 |
| **AI 助手** | 剧灵八字系统、3+ Skills、相关性判断 | AI 使用率 > 40% | P0 |
| **导出** | PDF/Word/Text 导出 | 可分享可打印 | P0 |

#### MVP 验收标准

- ✅ 用户可以在 30 分钟内完成第一个剧本场景创作
- ✅ AI 辅助功能使用率 > 40%
- ✅ 格式检查准确率 > 95%
- ✅ 获取 50 个种子用户，周活跃率 > 30%

### 2.3 分阶段规划

| 阶段 | 时间 | 核心功能 | 目标 |
|------|------|---------|------|
| **MVP** | 1-2 个月 | 基础编辑 + AI 辅助 | 验证核心价值 |
| **第二阶段** | 2-3 个月 | AI 共创 + 完整场景生成 | 提升创作效率 |
| **第三阶段** | 3-4 个月 | 实时协作 + AI 图片生成 | 团队协作 |
| **第四阶段** | 按需启动 | 团队工作区 + 移动端 | 生态完善 |

## 三、技术栈（引用）

> ⚠️ **完整的技术栈定义、选型对比、架构设计请参阅**：[技术栈文档 v1.0](../tech/tech-stack.md)

### 3.1 技术栈概要

| 层级 | 技术 | 说明 |
|------|------|------|
| **前端框架** | Next.js 14+ | App Router, SSR/SSG |
| **UI 组件** | shadcn/ui + Tailwind CSS | 纸质主题 (#F5F1E8 + #C9A962) |
| **编辑器** | TipTap | 无头设计、高度可定制 |
| **AI 文本** | 智谱 GLM-4.7 | 国产大模型、成本降低 95%+ |
| **AI 图片** | T8Star (nano-banana-2) | 专业图片生成服务 |
| **数据库 ORM** | Drizzle ORM | 高性能、SQL 透明、Edge 支持 |
| **数据库** | PostgreSQL 15+ | 关系型数据库 |
| **认证** | Casdoor | 独立部署、可视化管理、SSO |
| **拖拽** | @dnd-kit/core | 现代化拖拽库 |

### 3.2 关键技术决策

| 决策 | 选择 | 核心理由 |
|------|------|---------|
| **ORM** | Drizzle vs Prisma | 性能更好、包体积小、Edge 支持 |
| **认证** | Casdoor vs NextAuth.js | 企业级功能、可视化管理 |
| **AI 模型** | 智谱 GLM-4.7 | 成本降低 95%+、中文优化、国内合规 |
| **编辑器** | TipTap | 无头设计、剧本扩展成熟、支持协作 |

> 💡 **详细的技术选型对比、架构设计、部署方案请参阅**：[技术栈文档](../tech/tech-stack.md)

## 四、数据模型（引用）

> ⚠️ **完整的数据模型定义、实体关系、Schema 设计请参阅**：[数据模型文档 v1.0](../tech/data-model.md)

### 4.1 核心实体概要

```typescript
// 核心实体
Project           // 项目
Character         // 人物（含诗号、关系）
Scene             // 场景（含 TipTap JSON 内容）
WorldviewItem     // 世界观设定
Storyboard        // 分镜
AIConversation    // AI 对话历史
JulingConfig      // 剧灵配置（八字性格）
CreativeMilestone // 创作里程碑
User              // 用户（含配额）
```

### 4.2 关键数据结构

**项目 (Project)**：
- 支持多种剧本类型（电影/长剧/短剧）
- 支持横竖屏方向
- 阶段追踪（世界观 → 人物 → 剧本 → 优化 → 制作）

**人物 (Character)**：
- 诗号生成
- 性格标签、说话风格、行为模式
- 人物关系图谱

**场景 (Scene)**：
- TipTap JSON 格式存储
- 时长估算
- 集数/场景编号

> 💡 **完整的字段定义、实体关系图、数据库 Schema、索引策略请参阅**：[数据模型文档](../tech/data-model.md)
