## 核心概念

### 剧灵的创作理念

```
人类创意 + AI 智能 = 共生创作

不是 AI 替代人类，而是 AI 扩展人类的创作边界
```

### 产品定位

- **从**: 短剧剧本创作工具
- **到**: 编剧创作伙伴平台
- **核心**: AI 是工作伙伴，不是工具

### 创作流程

```
灵感捕捉 → 剧本创作 → AI 优化 → 作品完成 → 制作呈现
```

### 核心设计语言

- **纸质纹理** (#F5F1E8) - 还原真实纸张触感
- **古典金色** (#C9A962) - 唤起传统书写的专业感
- **三栏浸入式布局** - 最大化创作空间
- **专属剧灵系统** - 生辰八字决定性格，一人一灵
- **不打扰交互** - 静默观察，相关性判断

## 常见问题

**Q: PRD v2.4 和之前版本有什么区别？**
A: v2.4 是剧灵生辰八字系统版，核心变化是：每个用户只有一个专属剧灵，性格由注册时间（生辰八字）决定，AI不打扰用户创作，只在对话时展现智能。

**Q: PRD v2.4 和 v2.3 应该看哪个？**
A: v2.4 是最新的产品设计，包含剧灵生辰八字系统；v2.3 是优化整合版，包含详细的验收标准和风险分析。两者可以结合阅读。

**Q: 为什么将 UI 设计独立出来？**
A: 避免文档重复，设计规范可以独立维护和更新，同时方便前端开发快速查阅。

**Q: 如何开始开发？**
A: 按照 [实施计划 v2.1](../implementation-plan-v2.md) 中的 Sprint 规划，从基础架构开始逐步实现。该计划已更新为 Drizzle + Casdoor + GLM-4.7 技术栈。
