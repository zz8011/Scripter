# 剧灵 Scripter v5.0 原型设计文档

**版本：** v5.0 Spirit Edition
**创建日期：** 2026-01-24
**设计理念：** 优雅文人风格 — 剧灵是创作伙伴，不是工具

---

## 一、设计理念

### 核心定位
剧灵不是工具，而是用户的**专属 AI 创作伙伴**。根据用户注册时的生辰八字生成独特性格，以静默观察的方式守护创作，在关键时刻注入灵感。

### 美学方向
- **Tone**: 优雅文人风格 — 结合中国传统文人美学与现代设计
- **Color Palette**:
  - 纸质米白 (#F2EDE5) - 主背景
  - 墨色黑 (#0D0D0D) - 主文字
  - 金色 (#C9A962) - 强调色
  - 朱砂红 (#C8553D) - 点缀色
  - 玉色 (#5B7F6F) - 辅助色

### Differentiation
- 生辰八字系统 — 每个剧灵独一无二
- 诗号生成 — 剧灵的独特印记
- 静默观察模式 — 不打扰的创作陪伴
- 相关性判断 — 智能注入上下文
- 行为记录系统 — 全模块关键动作记录

## 三、核心设计元素

### 1. 剧灵展示组件
- **头像**: 圆形渐变背景，书法字"灵"
- **八字展示**: 四柱八字网格，天干地支
- **性格标签**: 五行属性对应的性格特点
- **诗号**: 剧灵的专属诗号
- **状态指示器**: 相关性状态（高/低）

### 2. 行为记录系统
- **观察记录**: 记录用户的操作（创建/编辑/删除/观察）
- **时间戳**: 每条记录的时间
- **分类标记**: 不同操作类型的颜色标记

### 3. 静默观察模式
- **状态徽章**: "静默观察中"
- **相关性指示**: 显示剧灵与当前创作的相关度
- **观察时长**: 统计观察时间

### 4. 交互设计
- **双栏收起**: 左右导航可收起，边缘切换按钮
- **拖拽功能**: 段落拖拽、场景卡片拖拽
- **格式检查**: AI 辅助格式检查面板
