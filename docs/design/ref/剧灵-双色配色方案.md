# Design Reference

## Original Prompt

为剧灵Scripter短剧创作平台设计两套完整的网站配色方案：浅色方案和深色方案。

设计要求：

## 整体设计框架

展示两套配色方案的完整对比，包括所有UI元素、背景、字体、图标等详细应用。

---

## 【第一部分】浅色方案 Light Theme

### 核心色值

**品牌金色系**

- 品牌金：#C9A962（主要强调色）
- 深金色：#A68A45（hover/active）
- 亮金色：#E6D3A3（背景高亮）
- 金色半透：rgba(201,169,98,0.1)

**背景与表面**

- 页面背景：#F5F1E8（温暖米色）
- 卡片/容器：#FFFFFF（纯白）
- 悬停背景：#FAF7F0（极浅棕）
- 禁用背景：#E8E4D6（浅米色）

**文字色系**

- 主文字：#1A1A1A（深黑）
- 次要文字：#5C5548（深褐）
- 辅助文字：#8B7355（中褐）
- 弱化文字：#A0A0A0（灰褐）
- 禁用文字：#C0B8A8（浅褐）

**边框与分隔**

- 边框色：#D3C9B0（浅褐）
- 分隔线：#E0D7C8（极浅）
- 焦点环：#C9A962（金色）

**语义色**

- 成功：#7FA870（橄榄绿）
- 信息：#7EA0C9（钢蓝）
- 警告：#E8A858（暖橙）
- 错误：#C96262（暗红）

**阴影系统**

- 浅阴影：0 2px 8px rgba(0,0,0,0.04)
- 中阴影：0 4px 12px rgba(26,26,26,0.05)
- 深阴影：0 8px 24px rgba(26,26,26,0.08)

---

## 【第二部分】深色方案 Dark Theme

### 核心色值

**品牌金色系**（保持一致）

- 品牌金：#C9A962（主要强调色）
- 深金色：#B89A5A（hover/active）
- 亮金色：#E6D3A3（背景高亮）
- 金色半透：rgba(201,169,98,0.15)

**背景与表面**

- 页面背景：#1A1A1A（深黑）
- 次级背景：#0F0F0F（纯黑）
- 卡片/容器：#2A2A2A（深灰）
- 悬停背景：#353535（中灰）
- 禁用背景：#1F1F1F（暗灰）

**文字色系**

- 主文字：#FFFFFF（纯白）
- 次要文字：#E0E0E0（亮灰）
- 辅助文字：#B0B0B0（中灰）
- 弱化文字：#808080（暗灰）
- 禁用文字：#606060（极暗灰）

**边框与分隔**

- 边框色：#404040（深灰）
- 分隔线：#2F2F2F（暗灰）
- 焦点环：#C9A962（金色）

**语义色**（与浅色保持一致）

- 成功：#7FA870（橄榄绿）
- 信息：#7EA0C9（钢蓝）
- 警告：#E8A858（暖橙）
- 错误：#C96262（暗红）

**阴影系统**

- 浅阴影：0 2px 8px rgba(0,0,0,0.4)
- 中阴影：0 4px 12px rgba(0,0,0,0.5)
- 深阴影：0 8px 24px rgba(0,0,0,0.6)

## 页面结构

### Section 1: 方案总览 Overview

- 左侧：浅色方案展示区
- 右侧：深色方案展示区
- 中间对比按钮，可切换主题

### Section 2: 背景色应用 Background Colors

展示：

1. 页面主背景
2. 卡片/容器背景
3. 悬停/激活背景
4. 禁用状态背景
5. 叠层深度效果

### Section 3: 文字色系 Typography Colors

展示：

1. 主标题（大号 + 强调）
2. 副标题（中号）
3. 正文文字
4. 辅助说明
5. 禁用文字

### Section 4: 图标应用 Icon Colors

展示：

1. 常规操作图标（#1A1A1A / #FFFFFF）
2. 品牌强调图标（#C9A962）
3. 语义状态图标（成功/错误/警告/信息）
4. 禁用图标
5. 悬停动画效果

### Section 5: UI 组件应用

- 按钮组件（主按钮、次按钮、文字按钮、危险按钮）
- 输入框（默认、焦点、错误、禁用）
- 卡片组件（默认、悬停、选中、禁用）
- 标签/徽章
- 进度条
- 切换开关

### Section 6: 完整页面示例

展示同一个页面在浅色和深色主题下的效果对比

### Section 7: 响应式布局展示

展示两套方案在移动、平板、桌面设备上的适配

### Section 8: CSS 变量代码

提供浅色和深色两套完整的CSS变量代码，可直接复制使用

---

## 设计细节

### 颜色卡片显示

- 色块展示
- 色值标签（HEX、RGB）
- 应用场景标签
- 复制按钮

### 对比度标注

- WCAG AA/AAA评级
- 可读性星级
- 推荐使用场景

### 交互效果

- 浅色/深色主题切换按钮（顶部）
- 色卡悬停提示
- 代码块复制功能
- 色值实时显示

### 视觉层次

- 深色主题：通过底色和发光效果营造科技感
- 浅色主题：通过阴影和间距营造专业感

---

## 技术要求

- 完全遵循Scripter设计系统规范
- 响应式设计（mobile/tablet/desktop）
- 浅色/深色主题完整切换（JavaScript实现）
- CSS变量系统完整
- 所有色值均可点击复制
- 无障碍设计（色彩对比度达标）
- 平滑的主题切换动画
