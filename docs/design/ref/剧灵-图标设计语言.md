# Design Reference

## Original Prompt
为剧灵短剧创作工具设计一个完整的Icon库。包含以下图标分类：

【品牌与导航】
- 剧灵Logo（黑金配色，32x32px）
- 返回箭头、菜单、关闭按钮

【编辑操作】
- 新建、保存、删除、编辑、复制、粘贴
- 撤销、重做
- 全屏、退出全屏

【剧本编辑】
- 大纲、场景、人物、对话框
- 导入、导出、下载
- 打印、分享

【内容管理】
- 人物（角色头像占位）
- 世界观（场景、设定）
- 场景库（图片框）
- 分镜（分格漫画框）

【功能操作】
- AI生成、刷新、加载
- 搜索、筛选、排序
- 添加、展开、收起

【状态指示】
- 成功✓、错误✗、警告⚠、信息ⓘ
- 草稿、已发布、锁定、解锁
- 加载中（旋转动画）、上传中（进度条）

【互动反馈】
- 点赞、收藏、评论、分享
- 下载、上传、刷新
- 设置、更多操作

所有图标使用统一的设计语言：
- 线条粗度：2px
- 圆角：2px
- 颜色：#C9A962（金色）、#1A1A1A（深黑）、#A0A0A0（灰色）
- 网格：32x32px 标准尺寸
- 风格：极简几何，与品牌气质一致

使用Lucide Icons作为基础，保持视觉统一性。所有图标排成网格展示，标注尺寸、颜色、用途。
