# Design Reference

## Original Prompt

为剧灵Scripter短剧创作平台创建一套完整的网站配色系统组件库。

设计要求：

## 配色系统概览

展示剧灵项目的完整色彩体系，包括所有语义色、状态色、渐变色和应用场景。

## 核心色彩分类

### 1. 品牌主色系

- **品牌金色**：#C9A962（古典优雅）
- **深金色**：#A68A45（hover/active状态）
- **亮金色**：#E6D3A3（背景高亮）
- **金色半透明**：rgba(201,169,98,0.1)

### 2. 中立色系

- **深黑**：#1A1A1A（主文字、UI主色）
- **纸质米色**：#F5F1E8（背景色）
- **白色**：#FFFFFF（卡片、输入框）
- **灰褐**：#5C5548、#8B7355、#A0A0A0

### 3. 语义色

- **成功绿**：#7FA870（确认、完成）
- **信息蓝**：#7EA0C9（AI相关、提示）
- **警告橙**：#E8A858（注意、草稿）
- **错误红**：#C96262（错误、删除）

### 4. 中性色调

- **边框色**：#D3C9B0（分隔线、边框）
- **悬停色**：#FAF7F0（背景悬停）
- **禁用色**：#A0A0A0（禁用状态）

## 展示内容

### 第一部分：色卡展示

- 每种色彩展示为方形色卡（100x100px）
- 色卡上显示：
  * 色彩名称（中英文）
  * 十六进制值
  * RGB值
  * 应用场景标签

### 第二部分：色彩应用场景

- **品牌金色应用**：按钮、链接高亮、强调文字
- **深黑应用**：标题、正文、UI框架
- **纸质米色应用**：主背景、卡片悬停
- **语义色应用**：状态指示、反馈提示

### 第三部分：渐变色方案

展示5种常用渐变组合：

1. 金色渐变：#C9A962 → #A68A45
2. 深黑渐变：#1A1A1A → #0a0a0a
3. 金黑渐变：#C9A962 → #1A1A1A
4. 米色渐变：#F5F1E8 → #FFFFFF
5. 语义渐变：#7FA870 → #7EA0C9

### 第四部分：无障碍检查

展示色彩对比度：

- 文字与背景的WCAG AA/AAA等级
- 各种组合的可读性评估

### 第五部分：CSS变量参考

提供完整的CSS变量代码块，可直接复制使用：

```css
:root {
  --paper-bg: #F5F1E8;
  --ink-black: #1A1A1A;
  --brand-gold: #C9A962;
  --brand-gold-dark: #A68A45;
  --brand-gold-light: #E6D3A3;
  --text-main: #1A1A1A;
  --text-sub: #5C5548;
  --text-muted: #8B7355;
  --border-color: #D3C9B0;
  --hover-bg: #FAF7F0;
  --white-bg: #FFFFFF;
  --success: #7FA870;
  --info: #7EA0C9;
  --warning: #E8A858;
  --error: #C96262;
}
```

## 设计风格

- 采用网格布局，井井有条
- 每个色卡有详细的信息标签
- 支持深浅两种主题展示
- 清晰的分类和分组
- 完整的应用场景说明

## 技术要求

- 完全应用Scripter设计系统
- 响应式设计
- 复制按钮快速获取色值
- 对比度计算显示
- 可交互的色彩预览
