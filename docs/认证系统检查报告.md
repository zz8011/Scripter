## 2. 认证流程

### 2.1 OAuth 登录流程
```
1. 用户访问 /login
2. 点击"使用 Casdoor 登录"
3. 前端调用 GET /api/auth/login
4. 后端生成 PKCE code_verifier 和 code_challenge
5. 后端返回 Casdoor OAuth URL
6. 前端重定向到 Casdoor 登录页
7. 用户在 Casdoor 完成登录
8. Casdoor 重定向到 /api/auth/callback?code=xxx&state=xxx
9. 后端用 code + code_verifier 交换 access token
10. 后端获取用户信息，创建/更新用户记录
11. 后端创建会话 cookie
12. 重定向到 /dashboard
```

### 2.2 开发模式登录流程
```
1. 用户访问 /login
2. 点击"开发模式快速登录"
3. 前端调用 POST /api/auth/dev-login
4. 后端创建开发测试用户（如不存在）
5. 后端创建会话 cookie
6. 跳转到 dashboard
```

### 2.3 登出流程
```
1. 用户点击登出
2. 前端调用 POST /api/auth/logout
3. 后端删除会话 cookie
4. 前端重定向到 /login
```

## 4. 会话管理

### 4.1 会话 Cookie
- 名称: `scripter_session`
- HttpOnly: true
- Secure: production 环境
- SameSite: lax
- 有效期: 7 天

### 4.2 开发模式
- 环境变量: `NODE_ENV=development`
- 可选绕过: `BYPASS_AUTH=true`
- 测试用户: dev@scripter.art

## 6. 配置要求

### 6.1 环境变量
```bash
# Casdoor 配置
CASDOOR_ENDPOINT=http://localhost:8000
CASDOOR_CLIENT_ID=your_client_id
CASDOOR_CLIENT_SECRET=your_client_secret
CASDOOR_CALLBACK_URL=http://localhost:3000/api/auth/callback

# 开发模式
NODE_ENV=development
BYPASS_AUTH=true  # 可选
```

### 6.2 Casdoor 应用配置
- 登录回调 URL: `http://localhost:3000/api/auth/callback`
- 允许的 scope: `openid`, `profile`, `email`

## 7. 安全建议

1. **生产环境**
   - 禁用 BYPASS_AUTH
   - 使用 HTTPS
   - 设置 Secure cookie
   - 配置正确的 CORS

2. **会话安全**
   - 定期轮换会话密钥
   - 实现会话过期提醒
   - 支持多设备登录管理

3. **OAuth 安全**
   - 验证 state 参数
   - 使用 PKCE
   - 限制回调域名
