## 一、核心概念

将 OpenClaw 的多 Agent 架构引入剧灵，让每个用户拥有一个**AI 创作团队**，而非单一的 AI 助手。

```
传统模式: 用户 ↔ 单一 AI
多 Agent 模式: 用户 ↔ 剧灵 Gateway ↔ 多个专业 Agent
```

---

## 二、Agent 分工设计

### 2.1 五 Agent 架构（基于五行）

| Agent | 五行 | 职责 | 性格特点 |
|-------|------|------|----------|
| **剧本医生** | 金 | 格式检查、结构优化、逻辑审查 | 精准、严谨、直接 |
| **角色教练** | 水 | 人物塑造、对白优化、性格一致性 | 智慧、灵活、深邃 |
| **情节策划** | 火 | 剧情设计、冲突构建、反转构思 | 热情、大胆、启发 |
| **场景设计** | 木 | 场景描写、氛围营造、视觉呈现 | 温和、成长、创造力 |
| **世界观构建** | 土 | 设定整理、一致性检查、背景完善 | 稳重、可靠、包容 |

### 2.2 Agent 协作流程

```
用户请求
    ↓
Gateway (意图识别 + 任务分发)
    ↓
├─ 格式问题 → 剧本医生
├─ 人物问题 → 角色教练
├─ 剧情问题 → 情节策划
├─ 场景问题 → 场景设计
└─ 设定问题 → 世界观构建
    ↓
Agent 协作 (可选)
    ↓
结果汇总 → 用户
```

## 四、交互设计

### 4.1 用户视角

**单 Agent 模式** (默认):
```
用户: 帮我看看这段对白
剧灵: (角色教练回复)
```

**多 Agent 协作模式** (复杂任务):
```
用户: 帮我完善这个场景
剧灵: 好的，我请场景设计师和剧本医生一起帮你

[场景设计] 建议增加环境描写...
[剧本医生] 格式上需要注意...
[角色教练] 对白符合人物性格

剧灵: 综合以上建议...
```

### 4.2 Agent 间对话

用户可以看到 Agent 间的讨论过程（类似群聊）:
```
[情节策划] 这里可以加个反转
[角色教练] 反转要符合人物动机
[世界观构建] 设定上允许这种反转
[剧本医生] 结构上没问题

[剧灵] 综合建议：可以在这里设置...
```

## 六、优势与挑战

### 优势 ✅
1. **专业分工** - 每个 Agent 深耕特定领域
2. **协作创作** - 模拟真实编剧团队协作
3. **性格多样** - 不同五行的 Agent 提供不同视角
4. **可扩展** - 随时添加新 Agent（如：台词专家、节奏大师）

### 挑战 ⚠️
1. **复杂度** - 多 Agent 协调比单 Agent 复杂
2. **成本** - 多个 Agent 调用增加 Token 消耗
3. **延迟** - Agent 间通信增加响应时间
4. **一致性** - 需要确保 Agent 间不冲突
