## 一、产品定位

### 1.1 产品名称

**中文名**：剧灵 (Jùlíng)
**英文名**：Scripter

### 1.2 一句话定位

> **剧灵，一支懂你的笔 — 让每个有故事的人都能成为编剧**

### 1.3 产品定义

剧灵是一个面向**所有有创作梦想的人**的 AI 剧本创作平台。通过深度集成的 AI 创作搭档系统，我们帮助用户从灵感到成品，完成完整的剧本创作旅程。

### 1.4 核心隐喻

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   从"我想写一个故事"                                         │
│          ↓                                                  │
│   到"这是一个完整的剧本"                                     │
│          ↓                                                  │
│   最终"它被拍摄成影像，感动了观众"                            │
│                                                             │
│   剧灵 = 你的 AI 创作搭档，全程陪伴                          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 二、产品愿景

### 2.1 愿景声明

> **"让每个有故事的人都能成为编剧"**

### 2.2 使命陈述

我们相信：

- 🌱 **每个人心中都有故事** — 只是缺少一个将其变成剧本的契机
- 🤝 **AI 是人类的工作伙伴** — 不是替代，而是合作、共创、共鸣
- 🚀 **创作门槛应该消失** — 好的创意不应因为技术门槛而被埋没

---

## 三、核心理念

### 3.1 AI 哲学

| 我们相信                    | 我们不认同              |
| --------------------------- | ----------------------- |
| AI 是创作搭档，陪伴人类创作 | AI 是工具，替代人类劳动 |
| AI 与人类共创，拓展边界     | AI 按令执行，单向输出   |
| AI 激发灵感，提供反馈       | AI 生成内容，人类审核   |

**核心表述**：> **"AI 不是工具，而是创作搭档"**

### 3.2 产品价值观

- **创作民主化** — 消除技术门槛，让创意落地
- **效率与质量并重** — 既提升速度，又保证专业
- **人机共创** — AI 陪伴而非替代，扩展而非取代
- **尊重创作者** — 用户保持创作主导权

## 四、目标用户

### 4.1 核心用户群体

| 用户类型             | 占比 | 核心需求           | 典型场景           |
| -------------------- | ---- | ------------------ | ------------------ |
| **业余创作者** | 40%  | 降低门槛、实现梦想 | 下班后、周末写故事 |
| **独立编剧**   | 30%  | 效率工具、专业提升 | 全职创作、接单养家 |
| **编剧新人**   | 20%  | 学习引导、快速入门 | 学生、转行者       |
| **专业团队**   | 10%  | 协作、版本管理     | 工作室、制作公司   |

### 4.2 用户语言

我们不说：

- ❌ "短剧编剧平台"（太窄）
- ❌ "专业写作工具"（太冷）

我们说：

- ✅ "有创作梦想的人"
- ✅ "想写故事的人"
- ✅ "创作者"

## 五、核心价值主张

### 5.1 四大核心价值

| 价值                   | 用户获益                 | 功能支撑                |
| ---------------------- | ------------------------ | ----------------------- |
| **降低创作门槛** | 新人也能快速上手         | 格式检查、模板引导      |
| **提升创作效率** | 节省时间，产出更多       | AI 辅助生成、润色、扩展 |
| **保证专业质量** | 符合行业标准，可直接制作 | 格式规范、导出制作文档  |
| **激发创作灵感** | 突破创作瓶颈             | AI 对话、反馈、建议     |
| **创作陪伴**     | 不再孤军奋战             | AI 创作搭档全程陪伴     |

### 5.2 差异化定位

|                | 传统软件 | 通用 AI    | **剧灵**             |
| -------------- | -------- | ---------- | -------------------------- |
| **定位** | 工具     | 聊天机器人 | **创作搭档**         |
| **关系** | 人用工具 | 人问 AI 答 | **人机共创**         |
| **场景** | 通用写作 | 通用对话   | **剧本创作专用**     |
| **输出** | 文档     | 文本片段   | **可直接拍摄的剧本** |

## 六、品牌语调

### 6.1 核心标语

**主标语**：

> **让灵感，在剧本中苏醒**

**副标语**：

> **AI 不是工具，而是创作搭档**
> **让创作，更高效专业**

### 6.2 品牌个性

| 属性             | 描述               | 不做          |
| ---------------- | ------------------ | ------------- |
| **专业**   | 懂剧本、懂创作     | ❌ 卖弄技术   |
| **友好**   | 陪伴式、鼓励式     | ❌ 说教式     |
| **启发性** | 提供灵感、打开思路 | ❌ 直接给答案 |
| **尊重**   | 用户主导，AI 辅助  | ❌ AI 主导    |

### 6.3 语言风格

**我们说**：

- ✅ "剧灵陪伴你创作"
- ✅ "让 AI 成为你的创作搭档"
- ✅ "我们一起完成这个剧本"

**我们不说**：

- ❌ "AI 替你写剧本"
- ❌ "一键生成专业剧本"
- ❌ "AI 自动创作"

## 七、产品边界

### 7.1 我们做什么

✅ **专注剧本创作**：

- 短剧、网络剧、电影剧本
- 格式检查、AI 辅助、项目管理
- 创作资源管理（人物、场景、世界观）

✅ **AI 创作搭档**：

- 生辰八字性格系统
- 不打扰的智能辅助
- 场景生成、对白润色、一致性检查

### 7.2 我们不做什么

❌ **不进入的领域**（至少 MVP 阶段）：

- 视频剪辑、后期制作
- 演员招募、场地租赁
- 剧本交易平台、版权售卖
- 社区论坛、社交功能

## 九、版本管理

### 9.1 版本规则

**格式**: `v{major}.{minor}`

| 类型            | 说明                     | 示例         |
| --------------- | ------------------------ | ------------ |
| **Major** | 定位方向重大调整（罕见） | v1.0 → v2.0 |
| **Minor** | 语言表述优化、补充说明   | v1.0 → v1.1 |

### 9.2 变更流程

```
1. 发现定位需要调整
       ↓
2. 产品团队讨论达成共识
       ↓
3. 创建新版本草稿（draft）
       ↓
4. 团队评审
       ↓
5. 发布新版本（approved）
       ↓
6. 更新所有引用本文档的材料
```

### 9.3 变更门槛

- **Minor 版本**：产品负责人审批
- **Major 版本**：产品团队 + 创始人共识
