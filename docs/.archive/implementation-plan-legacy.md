## Sprint 1: 基础架构 (Week 1-2)

### 目标
搭建项目基础架构，配置开发环境

### 任务清单

#### Week 1: 项目初始化

**开发环境**
- [ ] 安装 Node.js 18+, pnpm
- [ ] 初始化 Next.js 14 项目 (App Router)
- [ ] 配置 TypeScript, ESLint, Prettier
- [ ] 配置 Git Hooks (Husky + lint-staged)

**UI 配置**
- [ ] 安装 Tailwind CSS
- [ ] 配置品牌 CSS 变量（参考 `design/ref/剧灵·品牌标识规范.md`）
  ```css
  --paper-bg: #F5F1E8
  --brand-gold: #C9A962
  --ink-black: #1A1A1A
  ```
- [ ] 安装 shadcn/ui 组件库
- [ ] 配置自定义主题
- [ ] 安装字体（Inter, Noto Sans SC, Noto Serif SC, Courier Prime）

**认证系统**
- [ ] 安装 NextAuth.js
- [ ] 配置 GitHub OAuth
- [ ] 配置邮箱登录
- [ ] 创建登录/注册页面

**数据库**
- [ ] 设置 PostgreSQL (Neon/Vercel Postgres)
- [ ] 安装 Prisma
- [ ] 编写初始 Schema（User, Project）
- [ ] 运行首次迁移

#### Week 2: 基础组件

**导航布局**
- [ ] 创建根布局 (app/layout.tsx)
- [ ] 实现左侧导航栏（6项核心菜单）
  - 控制台、剧本、人物、场景、世界观、分镜
- [ ] 实现 Logo 区域（点击跳转欢迎页）
- [ ] 实现右侧 AI 面板框架
- [ ] 实现顶部工具栏

**基础组件**
- [ ] 创建 ProjectCard 组件（玻璃拟态）
- [ ] 创建 CharacterCard 组件
- [ ] 创建 SceneCard 组件
- [ ] 创建 Modal 组件（毛玻璃效果）

**路由结构**
- [ ] 创建 (dashboard) 路由组
- [ ] 创建基础路由页面
  - /dashboard
  - /projects/new
  - /projects/[id]/overview

### 验收标准
- [ ] 用户可以注册/登录
- [ ] 创建项目后可跳转到项目详情
- [ ] 导航栏在所有页面正常工作

## Sprint 2: 六大核心模块 (Week 3-6)

### 目标
实现 MVP 六大核心页面的基础功能

### 任务清单

#### Week 3: Dashboard + Editor 基础

**Dashboard (控制台)**
- [ ] 实现项目卡片流（玻璃拟态）
- [ ] 显示今日创作字数

**Editor 基础**

- [ ] 实现格式工具栏

- [ ] 人物小传编辑表单

**Scenes (场景)**

- [ ] 结构化展示
- [ ] AI 设定编织（接入）

**Storyboard (分镜)**
- [ ] 分镜脚本编辑器
- [ ] 画面-声音四栏排版
- [ ] 镜头类型选择
- [ ] AI 运镜建议（接入）

#### Week 6: 集成与优化

**集成测试**
- [ ] 六大模块联调
- [ ] 数据流转验证
- [ ] UI 统一性检查

**性能优化**
- [ ] 代码分割
- [ ] 图片优化
- [ ] 懒加载

### 验收标准
- [ ] 六大页面可正常操作
- [ ] 数据可正确保存
- [ ] 基础 UI 符合设计规范

## 开发规范

### Git 提交规范

```bash
feat: 新功能
fix: 修复 bug
docs: 文档变更
style: 代码格式（不影响功能）
refactor: 重构
test: 测试相关
chore: 构建/工具相关
```

### 代码审查检查清单

- [ ] 代码符合 ESLint 规范
- [ ] 添加必要的注释
- [ ] 更新相关文档
- [ ] 通过所有测试
- [ ] 无安全漏洞

### UI 开发检查清单

- [ ] 符合 [UI 设计系统](design/ui-design-system.md)
- [ ] 响应式适配（移动端/平板/桌面）
- [ ] 无障碍支持（键盘导航、ARIA）
- [ ] 动效流畅（60fps）
- [ ] 加载状态处理
