# 《我送君归去》短剧创作项目

## 项目简介

《我送君归去》是一部民国时期湘西赶尸题材的短剧，融合了神秘民俗、家国大义与悬疑元素，讲述了一位赶尸女为烈士送归遗骨，揭开惊天秘密的故事。

### 核心梗概

民国末期，湘西群山之间流传着神秘的"赶尸术"。红色资本家盛家重金请来赶尸女雾姝，希望她能送烈士盛伯安魂归故里。然而，这场"送君归去"的旅程，远比想象中更为复杂，一场惊天秘密被悄然揭开...

### 题材标签

```
民国 | 湘西赶尸 | 悬疑 | 家国大义 | 爱情
```

## 主要人物

### 雾姝（女主角）
**铜铃一响送魂归，半生孤行终自知。**

湘西赶尸世家传人，从执行者成长为守护者，肩负家国大义的"守魂人"。

### 盛世安（男主角）
**家国两难血与骨，愿以此身换清名。**

红色资本家后人，从背负者到抗争者，为证明家族清白而抗争。

### 江萋萋（女配角/反派）
**妒火深埋如罂粟，执念一生葬黄泉。**

因爱生恨的悲剧人物，被嫉妒吞噬。

### 张四爷（主要反派）
**笑里藏刀财如命，反噬临头鬼难饶。**

地方豪绅，与倭寇勾结的幕后黑手。
