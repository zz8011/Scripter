# 参考资料目录

本目录用于存放《我送君归去》创作过程中收集的各类参考资料。

## 建议参考资料分类

### 1. 历史资料
- [ ] 民国时期湘西地区历史背景
- [ ] 抗日战争时期地方势力
- [ ] 民国服饰、建筑、生活方式
- [ ] 红色资本家历史背景

### 2. 文化民俗
- [ ] 湘西赶尸术历史与传说
- [ ] 巫傩文化研究
- [ ] 湘西民间信仰与禁忌
- [ ] 道教符咒与法器知识

### 3. 地理环境
- [ ] 湘西地理环境与气候
- [ ] 皖南地理环境
- [ ] 湘西山区毒瘴现象

### 4. 剧作技巧
- [ ] 短剧剧本格式规范
- [ ] 悬疑剧节奏把控
- [ ] 人物关系构建技巧
- [ ] 民国题材剧作特点

### 5. 视听参考
- [ ] 类似题材影视作品
- [ ] 民国时期影像资料
- [ ] 湘西风光纪录片
- [ ] 赶尸相关影像资料

### 6. 对白参考
- [ ] 民国时期方言用语
- [ ] 湘西方言特点
- [ ] 不同阶层语言风格

## 使用方法

1. 将收集到的资料按分类放入相应子目录
2. 在资料文件名前添加日期便于管理（如：20260122_资料名称）
3. 重要资料可在创作笔记中记录引用索引

## 注意事项

- 仅用于创作参考，请勿直接抄袭
- 尊重历史事实，适当艺术加工
- 保密性资料注意版权保护
