# 《期货圆梦》深度优化计划

## 优化目标

将原剧本从 **92%符合率、4.2/5.0评分** 提升至 **98%符合率、4.8/5.0评分**

---

## 优化任务清单

### 🔧 任务1：格式规范化（优先级A）

#### 1.1 场景标题格式
**问题**：约24个场景（20%）标题格式不完全符合v2.0标准

**优化内容**：
```diff
- 当前：1-1 公司会议室 / 走廊 / 电梯 日 内
- 优化：**场1-1 日/内 公司会议室 主要人物：林微、李总、同事们**
```

**涉及场景**：
- 第1集：5个场景
- 第2集：3个场景
- 第4集：2个场景
- 其他散落场景：约14个

**预估修改**：24处

---

#### 1.2 时间描述标准化
**问题**：部分场景使用"夜晚"而非"夜"

**优化内容**：
```diff
- 当前：1-2 街道 / 西餐厅外 夜晚 外
- 优化：**场1-2 夜/外 街道/西餐厅外 主要人物：林微、陈宏斌**
```

**涉及场景**：约8个

**预估修改**：8处

---

#### 1.3 特殊标记统一
**问题**：电话音、闪回等标记不统一

**优化内容**：
```diff
- 当前：陈宏斌（电话音，焦急地带着哽咽）：
- 优化：陈宏斌（电话音，焦急哽咽）：

- 当前：【闪回快速镜头】
- 优化：【闪回】
```

**预估修改**：约15处

---

### 💬 任务2：对话优化（优先级B）

#### 2.1 拆分长对话
**问题**：8处长对话影响节奏和记忆

**优化列表**：

| 集数 | 行号 | 人物 | 原长度 | 优化策略 |
|------|------|------|--------|----------|
| 第22集 | 882-887 | 叶父 | 6句 | 拆分为3段，增加动作 |
| 第23集 | - | 林微 | 1段长篇 | 拆分，增加叶琳反应 |
| 第28集 | - | 林微 | 1段指控 | 拆分，增强节奏 |
| 第37集 | - | 叶琳 | 1段独白 | 拆分，增加表情 |
| 第42集 | - | 林微 | 1段决定 | 拆分，增加犹豫 |
| 第53集 | - | 林微 | 1段演讲 | 拆分，增强感染力 |
| 其他 | 2处 | 配角 | 长对话 | 拆分优化 |

**预估修改**：8处

---

#### 2.2 增加潜台词和对白层次
**问题**：部分对话过于直白，缺乏层次

**优化示例**：
```diff
# 原句
林微（语气斩钉截铁）：我都知道了，你在家等我，不许做傻事。

# 优化
林微（语气平静）：我都知道了。

林微（停顿，声音放柔）：你在家里等我。

林微（加重语气）：不许做傻事。

林微（OS）：伤害琳琳的人，我一个都不会放过。
```

**预估修改**：约15处

---

#### 2.3 专业术语生活化
**问题**：部分专业术语外行难以理解

**优化示例**：
```diff
# 原句
林微：你看成交量！
林微：放量不跌价，洗盘，有大资金在承接。

# 优化
林微（指着屏幕，眼神发亮）：你看成交量！

叶琳（茫然）：成交量...怎么了？

林微：价格在跌，但成交量却在放大，这说明什么？

林微（笃定）：有人在大量买入！他们在接散户抛出来的筹码，这是典型的洗盘手法！
```

**预估修改**：约10处

**成长点2**（第35集后）：

【场景】苏氏董事会被挑战
【表现】叶琳从容应对，展现领导力
