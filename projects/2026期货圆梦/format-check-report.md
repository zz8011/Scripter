## ⚠️ 需要改进的项目

### 1. 场景标题格式不统一

**问题描述**：
部分场景标题缺少人物列表，且格式不完全符合v2.0规范

**示例**：
```diff
- 当前格式：1-1 公司会议室 / 走廊 / 电梯 日 内
+ 建议格式：**场1-1 日/内 公司会议室 主要人物：林微、李总、同事们**
```

**影响场景**：约20%的场景（约24个）

**修复建议**：
- 添加粗体标记（**）
- 调整为"时间/内外"格式
- 添加主要人物列表

---

### 2. 部分动作描述存在抽象情绪

**问题描述**：
少数动作描述使用了抽象情绪词汇，不够可视化

**示例**：
```diff
- 当前：△ 林微眼神绝望
+ 建议：△ 林微眼中光彩尽失，瞳孔涣散
```

```diff
- 当前：△ 林微心中百感交集
+ 建议：△ 林微嘴唇微颤，眼眶泛红，双手不自觉地攥紧衣角
```

**影响场景**：约15%的动作描述（约30处）

**修复建议**：
- 将抽象情绪转化为具体动作和表情
- 增强视觉化和可拍摄性

---

### 3. 部分场景标题时间描述不够精确

**问题描述**：
部分场景使用"夜晚"而非"夜"

**示例**：
```diff
- 当前：1-2 街道 / 西餐厅外 夜晚 外
+ 建议：**场1-2 夜/外 街道/西餐厅外 主要人物：林微、陈宏斌**
```

**修复建议**：
- 统一使用"夜"而非"夜晚"
- 保持格式简洁

---

### 4. 闪回标记使用不规范

**问题描述**：
部分闪回场景使用了【闪回】标记，但不够统一和完整

**示例**：
```diff
当前：【闪回快速镜头】
建议：【闪回】
```

**修复建议**：
- 统一使用【闪回】开始标记
- 闪回结束时添加【闪回结束】标记
- 或使用转场描述替代

---

### 5. 电话音格式不统一

**问题描述**：
电话音标记方式不统一

**示例**：
```diff
当前格式1：陈宏斌（电话音）：
当前格式2：母亲（电话音，带着无奈的劝慰）：
```

**建议格式**：
```
陈宏斌（电话音）：喂，老婆？我加班呢
```

**修复建议**：
- 统一电话音标记格式
- 情绪描述放在括号内，但保持简洁

---

### 6. 部分对话过长

**问题描述**：
少数对话段落过长，不利于拍摄和演员记忆

**示例**：
第882-887行的叶父长篇对话

**修复建议**：
- 将长对话拆分为多句
- 中间穿插动作描述
- 增强节奏感
