# 世界观设定：苟在宗门修仙长生

## 时代背景

**时代类型**：古代架空修仙世界
**时间跨度**：数十年（从练气期到元婴期的成长历程）
**世界设定**：低武修仙世界，凡人与修士并存

## 地理环境

**宏观世界**：
- **景国**：凡人国度，修仙宗门的统治范围
- **修仙界**：宗门林立，实力为尊
- **仙道巅峰**：传说中的元婴之上，化神、炼虚等更高境界

**主要地点**：
- **青阳宗**：主角所在的修仙宗门
  - 清田山：外门弟子驻地，有一阶下品灵脉
  - 外门区域：灵田、灵药园、灵木场
  - 内门区域：灵气浓郁，高阶修士修炼之地
  - 宗门大殿：发布任务、发放资源

**环境特点**：
- 山川灵秀，灵脉分布不均
- 宗门占据灵脉之地，凡人居于外围
- 野外有妖兽出没，危险与机遇并存
- 天地灵气稀薄，修炼资源匮乏

## 社会规则

**社会阶层**（按修为划分）：
1. **练气期**（12层）：外门弟子，宗门底层
   - 练气前期（1-3层）：负责杂务
   - 练气中期（4-6层）：可种灵田
   - 练气后期（7-9层）：有一定地位
   - 练气大圆满（10-12层）：外门巅峰

2. **筑基期**：内门弟子，宗门中坚
3. **金丹期**：长老级别，宗门高层
4. **元婴期**：老祖级别，宗门最高战力
5. **更高境界**：传说中的人物

**灵根体系**（决定天赋）：
- **天灵根**：单灵根，千年难遇，修炼速度极快
- **地灵根**：双灵根，百年难遇
- **真灵根**：三灵根，中等资质
- **伪灵根**：四灵根，下等资质
- **五灵根**：最差资质，修炼缓慢，注定平庸

**核心社会规则**：
1. **修为至上**：实力决定一切，弱肉强食
2. **资源为王**：灵石、丹药、功法是争夺核心
3. **宗门利益**：个人服从宗门，背叛必死
4. **等级森严**：低阶修士必须尊敬高阶修士
5. **契约精神**：灵石契约、血誓等具有约束力

**社会风气**：
- 冷酷现实，同门竞争激烈
- 人情淡薄，利益至上
- 弱者无尊严，强者有特权
- 稳健谨慎，冒险者多死

## 修仙体系

**境界划分**：
```
练气期（12层）→ 筑基期 → 金丹期 → 元婴期 → 化神期 → 炼虚期 → ...
```

**修炼关键**：
- **灵根**：决定修炼速度和上限
- **功法**：影响修炼效率和战斗力
- **资源**：灵石、丹药、灵药是必需品
- **机缘**：奇遇、师父、宝物

**寿元限制**：
- 练气期：约百年
- 筑基期：约两百年
- 金丹期：约五百年
- 元婴期：千年以上
- 每突破一个大境界，寿元大增

## 修仙百艺

**辅助技艺**（低阶修士的生存之道）：
1. **丹道**：炼制丹药
   - 疗伤丹：黄芝丹等
   - 突破丹：辅助突破境界
   - 培元丹：恢复法力

2. **符箓**：绘制符咒
   - 攻击符：火球符、冰锥符
   - 防御符：护身符
   - 功能符：传音符、遁符

3. **阵法**：布置阵势
   - 聚灵阵：聚集灵气
   - 迷踪阵：困敌迷惑
   - 防御阵：守护洞府

4. **御兽**：驯养妖兽
   - 灵兽为伴
   - 协助战斗
   - 探索资源

**百艺价值**：
- 低阶修士修为低，靠百艺赚取灵石
- 百艺精通者受宗门重视
- 百艺需要天赋和资源投入
- 主角的金手指涵盖所有百艺

## 经济体系

**货币单位**：
- **下品灵石**：基础货币
- **中品灵石**：1中品 = 100下品
- **上品灵石**：1上品 = 100中品

**收入来源**：
- 宗门任务：种植灵田、守护灵药、外出采集
- 出售丹药/符箓：百艺所得
- 猎杀妖兽：获取材料
- 借贷/契约：高风险高收益

**支出项目**：
- 修炼资源：丹药、灵石、功法
- 生活开销：洞府、法器、符箓
- 债务利息：高利贷契约

**经济现实**：
- 外门弟子年均收入：1-5块下品灵石
- 突破丹药成本：10块下品灵石
- 高利贷利息：年息1块灵石（本金的10%）
- 贫富差距极大，强者垄断资源

## 特殊设定

**主角金手指：神秘金书**
1. **【蕴灵法】**：无上秘典，可逆天改命
   - 改善灵根资质
   - 提升修炼速度
   - 筑基稳固根基

2. **修仙百艺大全**：详尽记录所有技艺
   - 丹药：从低阶到高阶的所有丹方
   - 符箓：所有符箓的绘制方法
   - 阵法：各种阵法的布阵图谱
   - 御兽：妖兽的驯养和培育方法
   - 包罗万象，应有尽有

**金书特点**：
- 随主角穿越而来
- 他人无法察觉
- 内容逐步解锁
- 是主角稳健崛起的核心

## 核心主题

**苟道理念**：
- **藏锋守拙**：不显山不露水，低调做人
- **稳健谨慎**：不打无准备之仗
- **步步为营**：每一步都要稳妥
- **深谋远虑**：为长远发展布局

**种田元素**：
- 经营灵田，积累资源
- 研习百艺，提升实力
- 扩大人脉，建立势力
- 稳扎稳打，厚积薄发

**杀伐果断**：
- 该出手时毫不犹豫
- 斩草除根不留后患
- 利益优先，情义在后
- 绝不吃亏

**凡人流特色**：
- 主角资质平庸（五灵根）
- 没有显赫身世
- 靠智慧和谨慎生存
- 从底层一步步向上爬

## 禁忌与限制

**修仙禁忌**：
- 不可背叛宗门（死罪）
- 不可残杀同门（除非有理由）
- 不可泄露宗门机密
- 不可勾结魔道（如果设定有魔道）

**主角限制**：
- 资质差（五灵根），修炼慢
- 资源匮乏，需要精打细算
- 不能暴露金书秘密
- 不能轻易冒险（稳健为主）
- 初期实力弱，需要忍辱负重

**社会限制**：
- 契约具有约束力，违约有后果
- 高利贷合法但利息严苛
- 宗门不支持私人借贷，但不禁止
- 外门弟子地位低，容易被剥削

## 短剧改编要点

**保留核心**：
✅ 修仙体系和境界划分
✅ 灵根决定命运的设定
✅ 苟道稳健的核心理念
✅ 金手指（金书）的秘密
✅ 从底层逆袭的励志主题

**简化调整**：
🔄 境界简化：练气→筑基→金丹（短剧聚焦前期）
🔄 人物精简：保留核心角色，减少配角
🔄 冲突集中：早期矛盾聚焦债务和资源
🔄 节奏加快：80集快速成长到筑基期

**戏剧冲突**：
💥 债务危机：高利贷契约，年息滚利
💥 资源争夺：与其他弟子竞争
💥 身份压制：被师兄师姐欺负
💥 金书秘密：不能暴露的秘密
💥 突破难关：每次突破都是生死考验

**情感线**：
- 主角与债主师兄的对抗
- 与宗门高层的隐秘联系
- 可能出现的道侣（后期）
- 同门情谊（有限度）

**视觉奇观**：
- 修炼特效：灵气汇聚，法术光芒
- 法器战斗：飞剑、符箓、法阵
- 宗门场景：仙山楼阁，灵田药园
- 妖兽战斗：惊险刺激的战斗场面

## 世界观总结

这是一个**低武修仙世界**，实力为尊，资源匮乏。主角高平阳以**五灵根**的废柴资质，靠**神秘金书**的金手指，走**稳健苟道**路线，从青阳宗外门弟子一步步崛起。

**核心吸引力**：
- 🔥 逆天改命：废柴逆袭
- 🔥 稳健种田：资源积累
- 🔥 杀伐果断：快意恩仇
- 🔥 修仙百艺：全面发展
- 🔥 从零到英雄：励志成长

**短剧定位**：
男频修仙短剧，目标观众：喜欢修仙题材、废柴逆袭、稳健种田的男性观众。
